# Changelog

## 0.1.0

- Initial release.
- `Custom UI: Open` command opens a local-only, Apple-inspired Welcome-style Webview panel.
- Background image support (local file only) with opacity, blur, brightness, contrast, dark overlay, position, and fit controls.
- Light, dark, and high-contrast appearance support; respects `prefers-reduced-motion`, `prefers-reduced-transparency`, and `prefers-contrast`.
- Zero runtime dependencies. No network requests. No shell/process execution. No dynamic code execution.
